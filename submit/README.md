# Chiffre - Submission Files

This directory contains the files required for the submission of our **Chiffre** chip.

This includes:
- [out/](out/): The output files generated by OpenROAD
- [sw/](sw/): The software used, including the bootloader
- [chiffre_chip.gds.gz](chiffre_chip.gds): The GDS file of the **final** chip including the logo
